Search returns, for each source URL, a short summary written by an auxiliary model plus the URL. Read the summary as a lead, not as a quote: before a number, date or constraint enters a finding, confirm it is what the page says. If several results repeat the same upstream text, they are one source, not independent confirmation. When a search comes back empty it means "not found by this query", not "does not exist"; try a different phrasing before concluding anything.
